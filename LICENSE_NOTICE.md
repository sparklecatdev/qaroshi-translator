# Rights and source provenance

This project contains source-derived dictionary records and editorial bilingual examples from the Qaroshi language project (https://github.com/sparklecatdev/qaroshi).

The original language project states that its glyph artwork, written content and code have no explicit redistribution license yet. The repository owner must choose and document appropriate rights before public third-party redistribution or accepting contributions. This project does not imply that imported source data are public domain or licensed under MIT.

The new translator app code is supplied as an editable project artifact to the requesting repository owner. A formal license should be selected by the owner before general redistribution.

Full source archive member SHA-256 values are recorded in public/data/meta.json. The application does not include third-party audio recordings or font files.
